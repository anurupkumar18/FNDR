## Bugs found and fixed here

1. Escape in the Forget confirmation also closed the Settings sheet. The modal helper ignored `alertdialog` when deciding which dialog owns Escape. Fixed, with a regression test.
2. "remove 1 items" in the Forget dialog and button. Now pluralized.
3. Import permission errors read "permission needed: Files". They now use the plain next step already written in `ImportError::advice()`, with a test.
4. The failure reason was not in the log (`import:run_failed` only). It is now.
5. The permission note under each source sat at the contrast limit (4.55). Raised.
6. The dev preview lacked mocks for the MCP connect actions; added.
