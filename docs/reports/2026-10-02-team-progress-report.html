What shipped

  • Search has a measured baseline.

    VS-01 recorded Recall@5 0.955 and MRR@10 0.909 for Search, and 1.000 for Ask, on a 20-record knowledge-worker week. Every later search change can now be judged against it.

  • One memory followed through the real pipeline.

    VS-27 records a single memory from capture to result with event-backed evidence, and the six-journey baseline is staged behind it.

  • Capture became measurable and safer.

    ScreenCaptureKit one-shot capture, perceptual-hash dedupe with loop detection, per-stage p50 and p95 timings, and a Privacy Proof screen showing what was skipped and why.

  • The memory pipeline was audited and covered.

    MEM-01 to MEM-11: dead and duplicate code traced, finalization invariants under test, storage indexes, replay sessions with gold stories.

  • Screen Guide is steadier on Retina displays.

    Capture handoff and Retina OCR fixes landed this week, plus an explicit private mode. Full-screen stabilization (GS-15) is in progress.

  • The team runs on a board.

    GitLab labels, weekly milestones, issue and MR templates, TEAM.md, the demo script, and the agent-switch protocol all came from OPS-01 to OPS-12.

Next

Finish Screen Guide diagnostics (GS-15, GS-17), prove activity traces follow real process boundaries (PX-07), and run the six-journey human and agent baseline (VS-28).
