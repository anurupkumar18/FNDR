Locally.FNDR / On this Mac

A memory.
Not a
data mine.

Captured context, OCR, embeddings and search stay on your Mac by default. Optional cloud agent features use separately configured services. Local memory is not a blanket promise that every optional feature is offline.

No screenshot archive.No hosted memory account.No trackers on this site.
What gets remembered?+

FNDR stores structured memory records from explicitly enabled, permitted screen context, not a screenshot archive. Onboarding explains the permissions and on-device models needed.

What stays out?+

Pause capture at any time. Use Private Mode and the blocklist for apps or sites that should stay out of memory.

Can I change my mind?+

Delete records or set retention limits in the app. The source code and release artifacts are available to inspect on GitHub.

Download for Mac

macOS 13+ · Apple Silicon

Latest full release on GitHub

  1. Download.

    Choose Download for Mac. The DMG is for macOS 13 or later on Apple Silicon.

  2. Make room.

    Open the DMG, drag FNDR into Applications, then eject the installer.

  3. Start remembering.

    Open FNDR and follow onboarding for permissions and the on-device search model.

If macOS blocks the first open+

Developer ID releases are signed and notarized by Apple and should open normally. An ad-hoc signed build can require manual approval: open System Settings → Privacy & Security, find FNDR, choose Open Anyway, then confirm. Do not disable Gatekeeper.
