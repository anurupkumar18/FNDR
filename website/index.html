Privacy is product behavior

A memory should not become someone else's dataset.

FNDR stores captured context, OCR, and embeddings locally by default. Optional cloud agent features only use services explicitly configured in the app.

Capture control
Pause capture at any time and use the blocklist for specific apps or sites.
Deliberate storage
FNDR stores structured memory records and does not persist a screenshot archive.
Your exit
Delete records or set a retention limit from controls built into the app.
This website
No analytics, trackers, cookies, sign-in, or form collection.

From download to first search

Three steps. No developer tools.

  1. 1

    Download the DMG

    Choose Download for Mac. FNDR currently supports macOS 13 or later on Apple Silicon.

  2. 2

    Move FNDR to Applications

    Open the DMG, drag FNDR into Applications, then eject the installer.

  3. 3

    Open and finish setup

    Follow onboarding for the permissions and on-device search model FNDR needs. Each request explains what it enables.

If macOS blocks the first open

Developer ID releases are signed and notarized by Apple and should open normally. A release built with ad-hoc signing can show that macOS cannot verify the developer. Open System Settings → Privacy & Security, scroll to the FNDR message, choose Open Anyway, then confirm. Do not disable Gatekeeper.

Make the past work searchable.

One DMG. Future full releases arrive through FNDR's built-in updater.
